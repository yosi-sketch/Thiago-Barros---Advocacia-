# Thiago Barros — Advocacia e Consultoria Jurídica

Site institucional de advocacia criminal e de trânsito em Barbacena e região.

## Desenvolvimento

Instale as dependências com `npm install` e execute `npm run dev`. Abra http://localhost:3000.
Validação: `npm run lint` e `npm run build`.

## Marca e conteúdo

Next.js 16, React 19 e Tailwind CSS 4. O tema Tailwind fica em `app/globals.css`, com dourados extraídos do logo, preto e marfim. Cinzel nos títulos e Manrope nos textos.
Os quatro assets fornecidos ficam diretamente em `public`, com os nomes originais. Dados e links de contato estão centralizados em `app/site.ts`. WhatsApp: (32) 98899-5799; Instagram: @thiago.barrosadv. E-mail não informado e não exibido.
As avaliações são reproduzidas do texto fornecido pelo cliente. OAB/MG 221.217 transcrita do logo.
Configure `NEXT_PUBLIC_SITE_URL` com o domínio definitivo para ativar a imagem dos cartões de compartilhamento.
